## Verifiable offline vs. live-only

Offline (required, run by the implementer): typecheck, the full vitest suite, fake-driver scheduler tests, controller tests, and the local-fixture browser tests (127.0.0.1 only, no real site).

Live-only, NOT to be run by the implementer and NOT against the real government site: real before/after wall-clock (compare `events.log` timing lines against audit §2 baselines of 40-66 s without long CAPTCHA), server-side session locking on concurrent GET/POST, a prefetch landing on `/rs-captcha`, late server validators, and the 3x `off`/`verify`/`save` A/B on the same draft type. The final report must list these as "not verified" and keep the default at `off` until that A/B is done by the user.
